# NEXORA — Digital Store

Website statis untuk konsep toko top up game dan produk digital. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Fitur
- Tampilan modern, responsif untuk desktop dan mobile
- Pencarian produk dan filter kategori
- Katalog contoh: Free Fire, Mobile Legends, PUBG Mobile, Roblox, Valorant, Steam Wallet, Spotify Premium, dan Netflix
- Keranjang belanja dengan jumlah produk dan total otomatis
- Checkout demo yang menampilkan ringkasan pesanan

## Menjalankan
Buka `index.html` langsung di browser. Koneksi internet hanya diperlukan untuk memuat font Google Fonts; website tetap dapat dibuka tanpa font tersebut.

## Publikasi lewat GitHub Pages
1. Buat repository GitHub baru, misalnya `nexora-digital-store`.
2. Unggah `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan URL website di halaman Pages.

## Penting sebelum digunakan untuk jualan
Nama produk, harga, dan deskripsi di sini adalah contoh. Checkout belum terhubung ke WhatsApp, payment gateway, API supplier, atau database. Jangan menerima pembayaran nyata sampai sistem pemesanan, verifikasi pembayaran, dan pemenuhan produk sudah dikonfigurasi.
